# PSE em Ação — Sistema de Planejamento e Acompanhamento de Ações de Saúde na Escola

## Sobre o projeto

O **PSE em Ação** é um projeto acadêmico desenvolvido no contexto da **Atividade de Estudo Programado (AEP)** do curso de **Análise e Desenvolvimento de Sistemas** da Universidade Cesumar (Unicesumar).

O projeto propõe o desenvolvimento de uma aplicação em linguagem **C**, executada em terminal, com o objetivo de auxiliar uma equipe escolar e de saúde no **planejamento, registro e acompanhamento de ações coletivas do Programa Saúde na Escola (PSE)**.

A aplicação foi planejada para organizar informações como escola, tema da ação, data planejada, público-alvo, responsável, quantidade planejada de participantes, status da ação e quantidade efetiva de participantes.

O sistema utiliza exclusivamente **dados fictícios e coletivos**, não contemplando informações individuais de estudantes, diagnósticos, condições clínicas ou qualquer outro dado pessoal de saúde.

## Objetivo

Desenvolver uma aplicação computacional introdutória, utilizando a linguagem C, para auxiliar equipes escolares e de saúde no planejamento, registro e acompanhamento de ações coletivas do Programa Saúde na Escola (PSE), proporcionando uma organização clara das informações e respeitando os limites de privacidade dos estudantes.

## Funcionalidades previstas

O sistema deverá permitir:

* Cadastro de ações do PSE;
* Listagem de todas as ações cadastradas;
* Pesquisa de ações por código, escola ou tema;
* Atualização do status das ações;
* Registro da quantidade real de participantes quando uma ação for realizada;
* Geração de resumo geral das ações;
* Validação de dados inseridos pelo usuário;
* Validação das opções selecionadas nos menus.
