# Considerações Finais

O desenvolvimento do sistema PSE em Ação possibilitou aplicar, na prática, os conhecimentos adquiridos ao longo do curso de Análise e Desenvolvimento de Sistemas, especialmente os conceitos de lógica de programação, algoritmos, estruturas de dados, modularização e desenvolvimento de software utilizando a linguagem C.

A aplicação foi desenvolvida com o objetivo de auxiliar no planejamento, registro e acompanhamento de ações coletivas do Programa Saúde na Escola (PSE), disponibilizando funcionalidades para cadastrar ações, listar registros, pesquisar informações, atualizar status e gerar um resumo geral.

Durante o desenvolvimento, foram trabalhados conceitos como estruturas de repetição, condicionais, vetores, funções, estruturas (`struct`) e validação de dados. Também foram realizados testes para verificar o funcionamento das funcionalidades e o tratamento de diferentes situações de entrada.

Além da implementação, a documentação dos casos de uso, o manual do usuário e as evidências de execução contribuíram para organizar e demonstrar o funcionamento da aplicação, mantendo relação com o planejamento e os algoritmos elaborados na primeira etapa do projeto.

Como limitação, o sistema realiza o armazenamento das informações somente em memória durante sua execução. Dessa forma, os registros são perdidos quando o programa é encerrado. Uma possibilidade de evolução futura seria implementar armazenamento permanente em arquivos ou banco de dados, além de uma interface gráfica que facilitasse a utilização.

Conclui-se que os objetivos propostos para esta etapa foram alcançados por meio da construção de uma aplicação funcional, capaz de organizar informações sobre ações coletivas e apresentar dados de acompanhamento de maneira simples. O projeto também proporcionou uma experiência prática de desenvolvimento, documentação e validação de um sistema computacional.
